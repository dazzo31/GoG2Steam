# Security Policy

## Supported Versions

Only the latest release of GoG2Steam is actively supported with security patches and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in GoG2Steam, please report it privately:

1. Use GitHub's **Private Vulnerability Reporting** feature via the **Security** tab of this repository.
2. Alternatively, open a confidential issue or contact the maintainer directly through GitHub.

Please include:
- A description of the vulnerability and its potential impact.
- Clear reproduction steps or proof-of-concept scripts.
- Operating system and PowerShell version.

You will receive an acknowledgment within 48 hours, followed by a status update once verified.
